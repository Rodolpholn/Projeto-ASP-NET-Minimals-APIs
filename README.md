# 🚀 API REST com ASP.NET Minimal APIs

Projeto desenvolvido para implementação de uma API REST utilizando o conceito de Minimal APIs do ASP.NET, focando em performance, simplicidade e organização.

---

## 📌 Sobre o projeto

Este projeto demonstra a construção de uma API moderna utilizando **ASP.NET Minimal APIs**, permitindo criar endpoints de forma enxuta e eficiente.

---

## 🚀 Funcionalidades

✔ CRUD completo  
✔ Estrutura leve e performática  
✔ Organização de rotas  
✔ Integração com banco de dados  

---

## 🛠️ Tecnologias

- ASP.NET Core  
- C#  
- Minimal APIs  
- SQL  

---

## 📊 Objetivo

Aplicação criada para demonstrar boas práticas na construção de APIs modernas e escaláveis.
